## 📌 نبذة عن المشروع
منصة ويب متكاملة وتفاعلية لبيع وشراء السيارات الحديثة والفاخرة مدعومة بالذكاء الاصطناعي (**Google Gemini API**).  
تتيح المنصة تجربة متكاملة لثلاثة أدوار رئيسية (**المشتري / Buyer**، **البائع / Seller**، و**مدير النظام / Administrator**) مع دعم كامل للبحث باللغة الطبيعية، التسعير والتوصيات الذكية، الحجز، الدفع الإلكتروني، المحادثات المباشرة، ولوحة تحكم إدارية متطورة.

---

## 🛠️ التقنيات المستخدمة (Technology Stack)
- **Backend:** ASP.NET Core Web API (.NET 10)
- **Database:** Relational Database مع Entity Framework Core (3NF Schema)
- **AI Integration:** Google Gemini API (تحليل استفسارات اللغة الطبيعية وتوليد التوصيات والتقييم السوقي)
- **Authentication & Security:** JWT Tokens، تشفير كلمات المرور، ورمز التحقق الثنائي (2FA) للمديرين
- **Frontend:** HTML5, CSS3, JavaScript (Vanilla Modern SPA) بتصميم فاخر ومطابق لجميع شاشات التوثيق الجامعي (Chapter 5)، مع دعم كامل للغتين (العربية والإنجليزية) والوضع الليلي/الفاتح.

## 🎯 الميزات الرئيسية المنجزة
1. **بوابة المشتري (Buyer):**
   - البحث الذكي باللغة الطبيعية باستخدام Gemini AI (مثل: *"Find me a red SUV under $40,000"*).
   - الفلترة المتقدمة (الشركة، الموديل، السعر، سنة الصنع، الوقود: بنزين/كهرباء/هايبرد).
   - قسم التوصيات الذكية *"Cars You Might Like"* مع نسبة المطابقة الذكية (98% AI Match).
   - نافذة تفاصيل السيارة مع مؤشرات الذكاء الاصطناعي (القيمة التقديرية، درجة الاعتمادية 4.8/5.0، مستوى الطلب).
   - نظام حجز وتسليم متعدد الخطوات (Schedule Handover -> Payment Method -> Confirmation).
   - شاشة إدارة الحجوزات مع إمكانية عرض وطباعة الفاتورة الرقمية الرسمية (Digital Invoice).
   - تقييم ومراجعة البائعين (Ratings & Reviews).

2. **بوابة البائع (Seller):**
   - لوحة تحكم البائع (Seller Dashboard) مع إحصائيات الأرباح والمشاهدات ومخطط نمو المبيعات.
   - نصائح الذكاء الاصطناعي لتسعير السيارات وتحسين جودة الإعلانات (Listing AI Insights).
   - إدارة إعلانات السيارات (إضافة، تعديل، حذف، ومعاينة).
   - إدارة طلبات الحجز الواردة من المشترين (قبول / رفض).
   - سجل الأرباح والمبيعات مع إمكانية تصدير التقرير المالي كـ CSV.

3. **المحادثات المباشرة (Messaging Center):**
   - دردشة فورية بين البائع والمشتري مع عرض سياق السيارة في رأس المحادثة.
   - شارة ثقة الذكاء الاصطناعي (AI Trust Insight).

4. **لوحة تحكم المدير (Admin Console):**
   - مراقبة مؤشرات المنصة (إجمالي المستخدمين 24,892، الإعلانات النشطة 4,102، الإيرادات $1.42M، البلاغات المعلقة).
   - مراجعة واعتماد إعلانات السيارات (Approve / Reject مع تحديد السبب).
   - إدارة حسابات المستخدمين (تفعيل / تجميد) وتوثيق رخص معارض السيارات (Verify Seller).
   - مراقبة الصفقات المالية وسجل العمليات مع تصدير CSV.
   - معالجة البلاغات والشكاوى (Remove Listing / Suspend User / Dismiss).
   - ضبط إعدادات المنصة ومحرك تقييم الذكاء الاصطناعي.

5. **المساعد الذكي العائم (Floating AI Assistant):**
   - شات بوت ذكي متاح في جميع الصفحات للإجابة عن استفسارات السيارات والتمويل والفحص.
